# Changelog

All notable changes to NORU are documented in this file.

## 2.2.1 - 2026-07-27

- Add an evaluator-selection guide that distinguishes sparse global NNUE
  features from local categorical codebook representations.
- Link CB2Vec's workload-fit and benchmark documentation without presenting
  either evaluator family as a universal replacement for the other.
- Update the Gomoku application description to the current split between the
  NORU ordering model and a separate CB2Vec leaf evaluator.
- No library API, model format, training, quantization, or inference behavior
  changed.
